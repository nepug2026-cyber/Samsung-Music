# RetroSound One 0.6 — Android-проект для тестирования Samsung

## Статус

Это исходный Android-проект, а не уже собранный APK.
Файлы проверены на целостность; часть JS-интерфейса протестирована в браузере.
**Компиляция Android / тесты на смартфоне и в Android Auto не проводились**: в текущем окружении нет Android SDK, Gradle и устройства.

## Что включено

- Компактный экран телефона на WebView с интерфейсом RetroSound 0.5 и десятью полными оригинальными инструментальными композициями (локально, без интернета).
- Семь скинов, 10 персонажей, дневная/ночная тема, карусель источников, управление и настройки с прошлой версии демо.
- Android-мост: выбор сервиса из интерфейса телефона вызывает попытку возобновить его активную Android MediaSession; если медиасессии нет, по нажатию открывается официальное приложение (если установлено).
- Сохранение порядка источников между сессиями: `SharedPreferences(car_sources)` хранит настройки из WebView для автомобильного MediaLibraryService.
- Android Auto: `MediaLibraryService` + Media3 ExoPlayer, каталог из 10 включённых аудиофайлов, локальная MediaStore-библиотека (после разрешения на телефоне), раздел «Переключить источник».
- В разделе «Переключить источник» Android Auto показывает источники в утверждённом порядке. Уже существующую активную медиасессию внешнего сервиса можно **попытаться возобновить одним нажатием** при предоставленном доступе к уведомлениям. Если активной сессии нет, сервис не может произвольно переключать сторонние приложения, нужен штатный переключатель приложений Android Auto.
- TIDAL по умолчанию скрыт, его можно включить в настройках.

## Как получить APK через GitHub Actions (без Android Studio)

1. Создайте собственный GitHub-репозиторий (частный — по желанию).
2. Загрузите файлы **из папки проекта** `RetroSoundOne_0.6_Android` в корень этого репозитория (включая скрытую папку `.github`). При использовании ZIP сначала распакуйте его.
3. Откройте вкладку **Actions** и выберите **Build Samsung Android test APK**.
4. Нажмите **Run workflow**, если сборка автоматически не запустилась.
5. После успешной сборки откройте последний запуск, скачайте artifact **RetroSoundOne-0.6-test-apk**. Внутри будет файл `app-debug.apk`.
6. Скопируйте `app-debug.apk` на Samsung, откройте его в приложении «Мои файлы» и разрешите установку из данного источника, если Android спросит.

Workflow: `.github/workflows/build-apk.yml`. Он выполняет `gradle :app:assembleDebug` на GitHub runner с JDK 17 / Gradle 8.11.1 / Android SDK 35.

Если сборка завершится с ошибкой, приложите лог GitHub Actions. Это пока **не подтверждённая компиляция**.

## Android Studio

Используйте Android Studio с JDK 17, Android SDK API 35, Android Gradle Plugin 8.9.2 и Gradle 8.11.1. В этом архиве нет `gradle-wrapper.jar`: удобнее использовать GitHub Actions. Для локальной сборки предварительно установите Gradle 8.11.1, затем выполните `gradle :app:assembleDebug` в корне проекта. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка на Samsung

1. Запустите RetroSound One 0.6 и разрешите доступ к локальной музыке, если планируете слушать файлы смартфона через Android Auto.
2. Нажмите «♫ Коллекция» и попробуйте любую из десяти встроенных записей.
3. Проверьте семь скинов, персонажей и тему.
4. Откройте **Настройки → Источники → Разрешить управление музыкой**; в системном разделе дайте RetroSound One доступ к уведомлениям. Это необходимо, чтобы обнаруживать активные медиасессии других приложений.
5. В Яндекс Музыке / Apple Music / Spotify или другом официальном приложении запустите любой трек и оставьте активную медиасессию.
6. На RetroSound One выберите его в карусели. Отправится команда `play()` в активную медиасессию, если сервис её поддерживает; иначе откроется официальное приложение.
7. Настройки порядка и скрытия источников сохраняются для автомобильной библиотеки.

## Проверка Android Auto

**Тестировать только на стоящем автомобиле или на Android Auto Desktop Head Unit**.

1. Установите debug APK на телефон, подключите его к Android Auto.
2. Если RetroSound не появляется в списке, включите тестовую опцию **Android Auto → Настройки разработчика → Неизвестные источники** (название пункта зависит от версии). Официальное руководство: https://developer.android.com/training/cars/testing
3. В меню RetroSound One автомобильного интерфейса выберите «Демо: 10 композиций» → трек; проверьте Play/Pause/Next.
4. Откройте «Переключить источник». В списке должны быть восемь сервисов в утверждённом порядке. TIDAL не должен появляться, пока не включён.
5. Проверьте переключение на **уже активную** медиасессию другого музыкального приложения. После переключения сама система Android Auto может автоматически показать карточку нового сервиса.
6. Отдельно проверьте источник без активной сессии: появится инструкция использовать меню приложений Android Auto — автоматическое открытие гарантировать нельзя.

## Ограничения / честный статус

- Браузерный экран смартфона использует WebView — это тестовый мобильный интерфейс, а не полностью нативный Compose.
- WebView и Media3-сервис имеют **отдельные проигрыватели**. В тестовой сборке их состояния/очереди не синхронизированы; перед производственной версией нужно единое Media3-ядро и MediaController.
- Выбор произвольной папки в WebView может зависеть от Android System File Picker; воспроизведение локальных файлов в текущей HTML-части не гарантируется и не сохраняется после закрытия.
- Включённые демозаписи работают автономно. Spotify, Яндекс, КИОН и прочие сервисы **не встроены в приложение** и не предоставляют из него каталог или аудиопоток.
- В автомобиле нельзя показывать танцы и декоративный 3D-экран во время движения — используется системный автомобильный UI.
- Переключение внешних источников ограничено существующими медиасессиями, установленными приложениями, их API, разрешениями Android и поведением Android Auto.
- Потребуется тест на реальном телефоне Samsung и через Desktop Head Unit.
