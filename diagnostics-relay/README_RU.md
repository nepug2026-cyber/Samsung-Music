# Автоматическая отправка сбоев RetroSound One 1.4
1. Создайте Cloudflare Worker и разместите `worker.js` (или используйте свой HTTPS-сервер).
2. В секретах **самого Worker**, а не APK, настройте `RESEND_API_KEY`; в переменных среды: `REPORT_FROM` (почта на подтверждённом домене) и `REPORT_TO` (почта, на которую приходят ошибки).
3. Подтвердите домен отправителя у Resend, включите Cloudflare WAF rate limiting для `/report` и лимит на запросы, отключите сторонние логи входящих тел.
4. В GitHub Actions в Secrets/Variables укажите `RETROSOUND_DIAGNOSTICS_ENDPOINT=https://ВАШ-ДОМЕН/report`. Только HTTPS; это публичный URL, секреты почты в APK НЕ входят.
5. Новый debug APK создаётся workflow `build-apk.yml`, автоматически отправляет минимальные сообщения о сбоях через WorkManager при наличии Wi-Fi или мобильного интернета. При отсутствии сети хранит очередь и повторяет попытки.
6. Проверка: в APK → Настройки → Диагностика → «Тестовая ошибка»; дождитесь доставки, проверьте письмо и запомните SHA сборки. Если сервер не настроен, в APK будет «Адрес сервера ещё не настроен» — письма автоматически не уходят.
7. Журнал сохранён локально, не содержит названий композиций, приватных путей и текстов ошибок сторонних приложений. Пользователь может отдельно экспортировать .txt и удалить логи.
8. Не делайте Worker публичным без ограничений по частоте: это спам-риск. Не размещайте ключи почтового провайдера или адреса получателя в Android-приложении.
